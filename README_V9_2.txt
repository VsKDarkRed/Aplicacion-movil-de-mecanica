MECÁNICA VISUAL V9.2 — FUENTES OEM Y DESPIECES EN ESPAÑOL

Esta actualización conserva la aplicación V9.1 e incorpora un bloque visible de fuentes profesionales para consultar catálogos y documentación técnica.

Fuentes enlazadas:
- REPXPERT en español: https://www.repxpert.es/es/catalog
- TecDoc / TecAlliance: https://www.tecalliance.net/es/soluciones/tecdoc

IMPORTANTE:
- REPXPERT aporta catálogo de piezas y documentación técnica; no debe considerarse un EPC oficial completo para todas las marcas.
- La disponibilidad de diagramas, datos OE, búsqueda por VIN e idioma depende del proveedor, del producto y de los permisos de acceso.
- Para esquemas OEM auténticos, consulta la fuente oficial de la marca o un distribuidor autorizado.
- No se han inventado referencias ni se han presentado ilustraciones genéricas como despieces originales.
- No se copian ni redistribuyen bases de datos o dibujos protegidos sin autorización.

INSTALACIÓN:
1. Descomprime el ZIP.
2. Sube los archivos de la raíz al repositorio de GitHub Pages sustituyendo los correspondientes, no dentro de una carpeta adicional.
3. El archivo sw.js actualiza el nombre de caché a mecanica-visual-v9-2.
4. Abre la web en Safari y recarga. Si ves la versión anterior, cierra la pestaña y vuelve a abrirla.
5. Comprueba visualmente el bloque “Fuentes recomendadas para despieces reales”.

Validación realizada: sintaxis JavaScript inline, enlaces OEM y estructura ZIP. La publicación en GitHub y la comprobación en iPad deben realizarse en el dispositivo/repositorio.
